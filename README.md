Webify-AI is an AI-powered website generator that creates code and provides a live preview based on user prompts. Simply describe the website you want, and Webify-AI will generate the necessary code along with an interactive preview.

✨ Features
🚀 AI-powered website generation
📝 Real-time code preview
🎨 Fully interactive Monaco code editor
💡 Supports modern web technologies
⚡ Fast and efficient web container rendering
🛠️ Tech Stack
Frontend: React, Tailwind CSS, Monaco Code Editor
Backend: Node.js, Express.js
Database: MongoDB
Preview Engine: Web Containers

📥 Installation
Follow these steps to set up Webify-AI on your local machine:

1️⃣ Clone the repository
git clone https://github.com/KushalSharmaGit/Webify-Ai.git
cd Webify-AI
2️⃣ Install dependencies
npm install
3️⃣ Start the development server
npm run dev
📌 Usage
1. ✍️ Enter a prompt describing your website idea.
2.🤖 Webify-AI generates the code automatically.
3.🛠️ View the code using the built-in Monaco editor.
4.⚡ Preview the website in the preview section.
